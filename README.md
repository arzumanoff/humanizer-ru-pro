# Humanizer RU Pro

Объединённый русскоязычный skill для редакторской работы в Codex и совместимых AI-агентах.

## Основа проекта

Проект собран на основе идей и MIT-лицензированных материалов:

- `ilyautov/humanizer-ru` — русская стилистика, жанровая редактура, ритм и калибровка голоса;
- `Vladimir-Human/humanizer-ru` — модульная структура, безопасность входного текста, ложные срабатывания и аудит артефактов.

Это самостоятельная объединённая сборка, а не официальный форк одного из upstream-проектов.

## Возможности

- режимы `audit`, `light`, `neutral`, `conversational`, `business`, `technical`, `legal-safe`, `marketing`, `voice-match`;
- факт-замок для имён, дат, чисел, ссылок, команд и терминов;
- защита от инструкций внутри редактируемого текста;
- справочники по русскому языку, жанрам и ложным срабатываниям;
- лёгкий Python-сканер без внешних зависимостей;
- тесты и GitHub Actions.

## Использование

```text
Используй humanizer-ru-pro в режиме technical.
Сохрани команды, версии, имена файлов и порядок шагов.
Убери канцелярит и шаблонные вводные. Верни только итоговый текст.
```

## Сканер

```bash
python scripts/scan_text.py text.txt
python scripts/scan_text.py text.txt --json
```

## Тесты

```bash
python -m pytest tests
```

## Ограничение

Проект не является детектором авторства и не гарантирует прохождение AI-детекторов. Его задача — редакционное качество русского текста.
