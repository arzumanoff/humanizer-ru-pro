# Humanizer RU Pro

Объединённый русскоязычный skill для редакторской работы и длинной художественной прозы в Codex и совместимых AI-агентах.

## Основа проекта

Проект собран на основе идей и MIT-лицензированных материалов:

- `ilyautov/humanizer-ru` — русская стилистика, жанровая редактура, ритм и калибровка голоса;
- `Vladimir-Human/humanizer-ru` — модульная структура, безопасность входного текста, ложные срабатывания и аудит артефактов.

Книжная надстройка спроектирована с учётом общих архитектурных идей систем для длинной прозы: chapter-by-chapter writing, story bible, memory banks, continuity checks и reference-style profiling. Чужой код из проектов без совместимой или явно указанной лицензии не копируется.

Это самостоятельная объединённая сборка, а не официальный форк одного из upstream-проектов.

## Возможности

- режимы `audit`, `light`, `neutral`, `conversational`, `business`, `technical`, `legal-safe`, `marketing`, `voice-match`;
- факт-замок для имён, дат, чисел, ссылок, команд и терминов;
- защита от инструкций внутри редактируемого текста;
- справочники по русскому языку, жанрам и ложным срабатываниям;
- лёгкий Python-сканер без внешних зависимостей;
- книжный модуль `book/` для романов и длинной прозы;
- тесты `pytest`.

## Книжный модуль

`book/BOOK_SKILL.md` добавляет режимы:

- `book-plan` — замысел, синопсис, части, главы и сцены;
- `scene-draft` — черновик одной художественной сцены;
- `chapter-draft` — сборка главы из сцен;
- `line-edit-fiction` — художественная построчная редактура;
- `continuity-check` — проверка хронологии, состояний персонажей, мира и сюжетных линий;
- `reference-style` — построение абстрактного профиля по референсным текстам;
- `memory-update` — обновление story bible после утверждения главы.

В `book/templates/` находятся шаблоны книги, главы, персонажа и стилевого профиля. В `book/references/` — pipeline главы, правила continuity и работа по референсу.

## Использование редактора

```text
Используй humanizer-ru-pro в режиме technical.
Сохрани команды, версии, имена файлов и порядок шагов.
Убери канцелярит и шаблонные вводные. Верни только итоговый текст.
```

## Использование для книги

```text
Используй book/BOOK_SKILL.md в режиме chapter-draft.
Возьми данные из карточки главы, персонажей и story bible.
Сохрани точку зрения, индивидуальную речь персонажей и правила мира.
После черновика отдельно выполни continuity-check.
```

## Сканер

```bash

python scripts/scan_text.py text.txt --json
```

## Тесты

```bash
python -m pytest tests
```

## Назначение

Humanizer RU Pro помогает находить шаблонные конструкции, канцелярит, кальки, артефакты чат-ботов и другие признаки неестественного русского текста. Сканер используется как редакторский инструмент, а не как окончательный способ определения авторства. Результаты сторонних AI-детекторов могут различаться.
