# Pipeline написания главы

Каждая глава проходит отдельные этапы. Не объединяй их в один ответ, если пользователь явно не просит быстрый черновик.

## 1. Context load

Загрузи только необходимое:

- карточку текущей главы;
- последние 1–3 кратких резюме;
- актуальные состояния участвующих персонажей;
- связанные сюжетные линии и незакрытые крючки;
- правила мира, необходимые в этой сцене;
- профиль рассказчика и референсного стиля.

Не помещай в контекст всю книгу без необходимости.

## 2. Scene plan

Для каждой сцены зафиксируй цель персонажа, препятствие, поворот, исход и эмоциональный сдвиг.

## 3. Draft

Пиши сцену через действие, выборы, наблюдения и подтекст. Не объясняй эмоцию после того, как она уже показана. Не выравнивай речь всех персонажей.

## 4. Continuity check

Проверь время, место, знания персонажей, предметы, физическое состояние, отношения и правила мира.

## 5. Line edit

Убери шаблонность, лишнее объяснение, повтор смыслов и механические переходы. Сохрани намеренные повторы, ритм, фрагменты и особенности голоса.

## 6. Reader check

Оцени драматическую задачу, конфликт, изменение состояния, ясность, темп, подтекст, крючок и соответствие жанру.

## 7. Memory update

После утверждения главы обнови только подтверждённые факты: резюме главы, состояния персонажей, timeline, сюжетные линии, обещания читателю и незакрытые вопросы.
